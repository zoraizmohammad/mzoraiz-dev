# Research project-page migration

The portfolio uses a shared Clarity-inspired research layout without inheriting the reference template's typography. Each page combines an editorial cover, a concise abstract, technical metadata, a system flow, and evidence-aware narrative sections.

## Content order

1. Project number, research area, title, abstract, author line, repository action, and 4:5 poster.
2. Compact on-page navigation.
3. System flow or a native SVG architecture diagram.
4. Problem, approach, design principles, present state, and next project.
5. Add repository-grounded figures, equations, benchmarks, and limitations during deeper migrations.

## Poster contract

All project posters are 1600 × 2000 px. The collection uses restrained geometric metaphors, warm paper texture, a limited sage/mustard/deep-green/coral palette, and generous negative space. Raster posters are conceptual covers—not technical diagrams—and contain no generated text.

## Evidence rules

- Read the source repository before describing implementation or results.
- Trace numerical claims to checked-in data, reports, or reproducible scripts.
- Label simulations, exploratory notebooks, prototypes, and physical validation precisely.
- Use SVG for systems and flows, real plots for measurements, and properly formatted math for models.

## Visual QA

Run the site locally and inspect desktop and mobile screenshots after every substantial migration. Iterate on margins, fonts, colors, alignment, image cropping, and overflow until the page is publication-ready.
